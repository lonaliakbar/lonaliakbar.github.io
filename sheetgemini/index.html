Kontrol Spreadsheet

Ketik perintah bahasa biasa — Gemini akan memanggil fungsi yang sesuai.

Memeriksa pengaturan...
Ambil gratis di aistudio.google.com/apikey. Tersimpan di Script Properties, tidak ikut terkirim ke halaman lagi setelah disimpan.
Tempel URL lengkapnya (boleh juga ID mentah). Akun yang menjalankan web app ini harus punya akses edit ke spreadsheet tersebut.
Contoh perintah:
"buat sheet baru bernama Oktober"
"tambahkan baris: Ali, 500000, lunas ke sheet SPJ"
"urutkan sheet Data berdasarkan kolom 2 dari kecil ke besar"
